## Application linéaire et multilinéaires

Que dire sur les applications linéaires dans un EV de dimension finie.
Et donner la démonstration.
?
Thorème: Toute application linéaire dont l'ensemble de départ est de dimension finie est continue.
**Démonstration.** 
Soient $F$ un $\mathbb{K}$-espace vectoriel normé de dimension quelconque et $u\in\mathcal{L}(E,F)$. 
Soit $x=\sum_{i=1}^n x_ie_i\in E$. 
Alors $\|u(x)\|=\left\|\sum_{i=1}^n x_iu(e_i)\right\|\leq\sum_{i=1}^n|x_i|\cdot\|u(e_i)\|$. 
Posons $\beta=\max_{1\leq i\leq n}\|u(e_i)\|$. 
Pour tout $x=\sum_{i=1}^n x_ie_i\in E$, $\|u(x)\|\leq\beta\sum_{i=1}^n|x_i|=\beta N(x)$. 
$u$ étant linéaire, on en déduit qu’elle est $\beta$-lipschitzienne, donc $u$ est continue.

### Application multilinéaires

Que dire dans le cas d'une application multilinéaire. Càd une application d'enseble de départ $E_1\times E_2\times...\times E_p$ a valeur dans F.
?
Théorème: Toute application $p$-linéaire dont les espaces de départ sont de dimension finie est continue.
==Warning: démonstration ci dessou recopié par l'IA il a prit des racourcis de zinzin==
**Démonstration.**  
Pour tout $j\in{1,\ldots,p}$, on note $n_j$ la dimension de $E_j$ et $e_j=(e_{1,j},\ldots,e_{n_j,j})$ une base de $E_j$. 
Soit $f$ une application $p$-linéaire de $E_1\times\cdots\times E_p$ dans $F$. 
Soit $(x_1,\ldots,x_p)=(\sum_{i=1}^{n_j}a_{i,j}e_{i,j})_{1\leq j\leq p}\in E_1\times\cdots\times E_p$. 
Par linéarité selon chaque variable, on obtient:
$$
f(x_1,\ldots,x_p)=\sum_{(i_1,\ldots,i_p)\in{1,\ldots,n_1}\times\cdots\times{1,\ldots,n_p}}a_{i_1,1}\cdots a_{i_p,p}f(e_{i_1,1},\ldots,e_{i_p,p})
$$
Soit $j\in{1,\ldots,p}$ et $i\in{1,\ldots,n_j}$. 
On a $a_{i,j}=e^*_{i,j}(x_j)$, où $(e^*_{k,j})_{1\leq k\leq n_j}$ désigne la base duale de $e_j$. 
Or $e^*_{i,j}$ est une application linéaire dont l'espace de départ est de dimension finie, donc elle est continue. 
L'expression précédente de $f(x_1,\ldots,x_p)$ et les théorèmes usuels sur les sommes et produits de fonctions continues montrent alors que $f$ est continue.
