
## Les différents types d'OSINT

| OSINT        | Description                                                                                                      |
| ------------ | ---------------------------------------------------------------------------------------------------------------- |
| SOCINT       | Social Media Intelligence (retrouver tous les comptes, intéraction réseaux)                                      |
| FININT       | Financial Intelligence (données financière d'entreprise...)                                                      |
| GEOINT/IMINT | Image Intelligence (find localisation from images)                                                               |
| SIGINT       | Signal intelligence (from radio signals and listenning what is over the air... airplanes... --> electronic coms) |
| RECON        | poru la cyber (reconnaissance des sites et leurs surfaces... pour attaques)                                      |

## Skills

There are a lot of differnt skills that are useful to each type of OSINT.
A few examples are google dorking, wayback-machine, archive.ph, forensic web browsers extensions, osint-tracker...

les outils périment ou deviennent obselète, l'important c'est la méthodologie:
1. Capacité d'analyse critique
2. Curiosité
3. Rigueure
